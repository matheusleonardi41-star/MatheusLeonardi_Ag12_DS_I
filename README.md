# Meus sites favoritos — Agenda 12 DS I

Projeto desenvolvido para a atividade de Desenvolvimento de Sistemas I.

## Arquivos
- `index.html`: página com cinco sites favoritos, imagens, links e comentários no código.
- `imagens/`: imagens SVG locais usadas na página.

## Como abrir
1. Baixe o projeto.
2. Mantenha a pasta `imagens` no mesmo local do arquivo `index.html`.
3. Abra `index.html` em um navegador.

## Como enviar para o GitHub
1. Acesse https://github.com/ e crie um repositório público chamado `MatheusLeonardi_Ag12_DS_I`.
2. Envie o arquivo `index.html`, a pasta `imagens` e este `README.md`.
3. Para publicar o site, abra **Settings > Pages**, selecione a branch `main` e a pasta `/ (root)`, e salve.
4. Aguarde e acesse o endereço que o GitHub Pages mostrar.

## Capturas para a entrega
Faça uma captura do código `index.html` no editor, mostrando os comentários, e outra da página aberta no navegador. Inclua essas capturas no envio da atividade conforme a orientação do professor.
